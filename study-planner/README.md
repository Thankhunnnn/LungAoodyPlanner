# Study Planner 🌸

เว็บแอปวางแผนอ่านหนังสือสอบ ใช้ได้ทั้งบนโน้ตบุ๊กและมือถือ

## ฟีเจอร์
- ⏰ นับถอยหลังวันสอบแต่ละวิชา (วัน / เวลา / ห้องสอบ)
- 📖 ตารางอ่านรายวัน ติ๊กได้ว่าอ่านเสร็จแล้ว + **จัดตารางอัตโนมัติ** จากวันสอบและจำนวนบท
- 📚 ใส่บท/หัวข้อของแต่ละวิชา, แถบความคืบหน้า, จดโน้ตแต่ละบท
- 🃏 แฟลชการ์ด + ❓ ข้อสอบปรนัย (สร้างเองหรือให้ AI สร้าง)
- 📅 ปฏิทินรวมวันสอบ การบ้าน กิจกรรม และแผนอ่าน
- ⏱️ Pomodoro + บันทึกเวลาอ่าน
- 📊 สถิติชั่วโมงอ่านรายวัน/รายสัปดาห์/แยกวิชา, streak
- 🤖 แท็บ AI ติว (Gemini หรือ OpenAI): ถาม-ตอบ, สรุปโน้ต, สร้างแฟลชการ์ด/ข้อสอบ, จัดตารางใหม่ตามเงื่อนไข
- 🔔 แจ้งเตือนทุกวันว่าต้องอ่านอะไร
- 🎨 6 ธีม + โหมดมืด
- ☁️ Sync ข้ามเครื่องด้วย Firebase (ไม่บังคับ) + Export/Import ไฟล์สำรอง

---

## 1) เปิดใช้งานบนคอม (ง่ายสุด)
ดับเบิลคลิก **`start.bat`** → เบราว์เซอร์จะเปิด `http://localhost:8080` ให้เอง
(ปิดหน้าต่างดำเพื่อหยุด) — ข้อมูลจะเก็บในเบราว์เซอร์ของเครื่องนั้น

> เปิด `index.html` ตรงๆ ก็ใช้ได้ แต่การแจ้งเตือน / ติดตั้งเป็นแอป / ล็อกอิน Firebase จะใช้ไม่ได้

## 2) เอาขึ้นเว็บเพื่อใช้บนมือถือด้วย (ฟรี)
วิธีง่ายสุด **Netlify Drop**:
1. เข้า https://app.netlify.com/drop (สมัครฟรีด้วย Google ได้)
2. ลากโฟลเดอร์ `study-planner` ทั้งโฟลเดอร์ไปวาง
3. จะได้ลิงก์ เช่น `https://xxxx.netlify.app` → เปิดได้ทั้งคอมและมือถือ
4. บน iPhone: เปิดลิงก์ใน Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** (จะได้เป็นแอป + รับแจ้งเตือนได้)
   Android: Chrome → เมนู ⋮ → **ติดตั้งแอป**

## 3) ตั้งค่า Sync ข้ามเครื่องด้วย Firebase (ทีละขั้น)
1. เข้า https://console.firebase.google.com → **Create a project** (ตั้งชื่ออะไรก็ได้, ปิด Google Analytics ได้)
2. เมนูซ้าย **Build → Authentication** → Get started → แท็บ *Sign-in method* → เปิด **Google** → Save
3. **Authentication → Settings → Authorized domains** → Add domain → ใส่โดเมนเว็บของคุณ เช่น `xxxx.netlify.app`
   (`localhost` มีให้อยู่แล้ว)
4. เมนูซ้าย **Build → Firestore Database** → Create database → เลือก location `asia-southeast1` → *Start in production mode*
5. แท็บ **Rules** ของ Firestore แทนที่ด้วยโค้ดนี้แล้วกด Publish:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```
6. กลับหน้า Project Overview → กดไอคอน **`</>`** (Web) → ตั้งชื่อแอป → Register
   จะเห็นโค้ด `const firebaseConfig = { ... }` → **คัดลอกทั้งก้อน**
7. ในแอป ไปที่ **ตั้งค่า → Sync ข้ามเครื่อง** → วาง config → กด *บันทึกและเชื่อมต่อ* → *ล็อกอินด้วย Google*
8. ทำข้อ 7 ในทุกเครื่องที่จะใช้ (ล็อกอิน Google บัญชีเดียวกัน) ข้อมูลจะ sync อัตโนมัติ

> ข้อมูลที่ sync: วิชา บท โน้ต ตาราง การบ้าน เวลาอ่าน แฟลชการ์ด และการตั้งค่า
> **ไม่ sync**: API key ของ AI และประวัติแชท (เก็บเฉพาะเครื่องเพื่อความปลอดภัย)

## 4) ตั้งค่า AI
**Gemini (แนะนำ, มีโควตาฟรี)**: https://aistudio.google.com/apikey → Create API key → วางใน *ตั้งค่า → AI*
**OpenAI**: https://platform.openai.com/api-keys → Create key (ต้องเติมเงิน) → เลือก OpenAI ในตั้งค่า แล้ววาง key
ชื่อรุ่นโมเดลแก้ได้เองในหน้าตั้งค่า ถ้ามีรุ่นใหม่ออกมา

## วิธีใช้เร็วๆ
1. **แต่ละวิชา** → + เพิ่มวิชา → ใส่ชื่อ วันสอบ เวลา ห้อง และบท (บรรทัดละบท)
2. **ตารางอ่าน** → ตั้ง "อ่านวันละ N บท" → กด **✨ จัดตารางอัตโนมัติ**
3. แต่ละวันติ๊กสิ่งที่อ่านเสร็จ — ถ้าอ่านไม่ทัน กดจัดตารางใหม่ หรือให้ AI จัดตามเงื่อนไข
4. ใช้ **จับเวลา** ระหว่างอ่าน เวลาจะไปโชว์ในหน้า **สถิติ**

## ไฟล์
```
index.html, styles.css      หน้าเว็บ + ธีม
js/store.js                 ข้อมูล + ฟังก์ชันวันที่
js/scheduler.js             จัดตารางอัตโนมัติ
js/ai.js                    เชื่อม Gemini / OpenAI
js/sync.js                  Firebase sync
js/services.js              แจ้งเตือน + Pomodoro
js/app.js                   หน้าจอทั้งหมด
sw.js, manifest.json        ติดตั้งเป็นแอป / ใช้ออฟไลน์
start.bat / start.ps1       เปิดเซิร์ฟเวอร์บนเครื่อง
```
